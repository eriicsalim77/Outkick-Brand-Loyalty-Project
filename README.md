# Outkick Brand Loyalty Project

## Overview
This project explores user engagement and growth opportunities for OutKick by identifying behavioral gaps and translating them into actionable product-driven solutions.

## Problem
OutKick has strong traffic and audience reach, but there are opportunities to deepen engagement, retention, and user loyalty.

## Approach
- Analyzed user behavior and engagement patterns
- Spoke with stakeholders to understand business context
- Identified key gaps in user experience and retention
- Developed a growth initiative and presented it to the team

## Key Takeaways
- Growth is driven by understanding user behavior, not just traffic
- Clear problem framing leads to stronger solutions
- Iterating quickly and presenting insights builds ownership
